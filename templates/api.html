We have a Prime API now. Wow!

/api/random

Returns a random prime. Primes are sampled uniformly based on the size of the database on query.

/api/index

Gets the nth prime

n = 1 indexed prime index

/api/check

Checks if a given number is prime

num = number to check

/api/generate/by-index

Generates a list of primes from their indices. If the number of requested primes exceeds 250,000, the request is paginated and the response contains a link to the next set.

lower = Inclusive lower bound of prime index

upper = Inclusive upper bound of prime index

/api/generate/by-range

Generates a list of primes within a range. If the number of requested primes exceeds 250,000, the request is paginated and the response contains a link to the next set.

lower = Inclusive lower bound

upper = Inclusive upper bound
